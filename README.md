# RoadGuard AI 🚧

AI-powered road damage detection and analysis system.

## Target classes
- Longitudinal crack
- Transverse crack
- Alligator crack
- Pothole

## Structure
```
RoadGuard-AI/
├── README.md
├── requirements.txt
├── .gitignore
├── app/
├── src/
├── models/
├── data/
└── docs/
```

## Setup
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Dataset and trained weights are intentionally excluded from Git.

## Status
Initial project scaffold. Training, inference, analytics and reporting will be added next.
